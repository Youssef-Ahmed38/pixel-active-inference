## Summary

- **Fresh seeds, default config (MockWorld).** The old numbers hold up. Discovery agent over all solvable cases: train 101.1 -> 99.7 actions, test 112.6 -> 111.6, success 99.9% on both splits. Every per-case interval overlaps the old one. The largest shifts are test key_drawer (222.0 -> 202.2) and test key_table (197.1 -> 209.4). Explanation accuracy and giving up are unchanged: 100% of no-solution scenes gave up. The baselines moved by about as much as their wide intervals allow.
- **Locality off (MockWorld).** Solving does not depend on the locality prior, but it gets slower. All solvable: train 99.7 -> 144.7 actions, test 111.6 -> 158.8. Success is 98.9% / 98.8%, with 7/1200 solvable scenes per split wrongly given up. Explanation accuracy drops by 0.03-0.09 on the lock cases, and there are more false claims (for example test latch 0 -> 35).
- **Shared shapes (MockWorld).** Decoys that look like the mechanisms cost about as much as removing locality: all solvable 144.9 train and 157.4 test. The novelty and random baselines also get worse, and the discovery agent keeps its 2.3-2.8x lead over them. Shape is only a weak cue.
- **Both off (MockWorld)** is the hardest setting: all solvable 202.4 train and 227.2 test, success 99.0% / 98.0%. It still takes about 1.5x fewer actions than the default-config novelty baseline (312.1 train, 332.3 test). The no-solution stop within 1000 actions fires in only 62% (train) and 54% (test) of scenes, so a larger budget is needed to judge giving up here.
- **Recipe reuse** helps in both configs. Under both_off the paired saving is larger in absolute terms: for example, deadbolt test -93.9 [-123.7, -70.9] actions against -12.2 under default. It is also larger in relative terms: 142.8 -> 48.9 against 36.3 -> 24.1.
- **PhysicsWorld with physical decoys** is much worse than the old decoy-free run. Default config: 12/25 solvable episodes opened, against 18/25 before. Latch and deadbolt stay at 5/5, but the key cases fall: key_table 3/5 -> 1/5, key_drawer 2/5 -> 0/5, both 3/5 -> 1/5. Latch now takes 26 actions against 6 before, and decoys take about half of all physics actions: 3213 of 6248 actions under default and 2972 of 7328 with locality off (`decoy_actions_*.json`, counted with `logs/decoy_actions.py`). With locality off, 8/25 opened (deadbolt 2/5). No physics no-solution episode gave up within 300 actions, same as before (0/5). The 300-action budget is what limits the key cases in physics; these are 30 episodes per config, so treat the physics rows as indicative.
- **Deviations from the old physics design:** the per-episode wall limit is 3000 s instead of 600 s, because decoys make episodes slower. The longest episode took 1354 s, and no episode hit the limit. The default physics run used 5 worker processes, the loc_off run 8.
