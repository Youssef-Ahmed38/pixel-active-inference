## Findings (hand-written for this run; regenerating the file drops this section)

- **All three students nearly reach the Bayes ceiling** (59.6-59.8% vs 60.2% for the teacher; ECE under 0.01).
  At the same number of training examples, the **HRM does not beat the baselines**. The 4-layer one-shot
  transformer is best (KL 0.0026 vs 0.0064), and it trains ~9x faster. This task can be solved in a single
  feed-forward pass (the posterior is one matched-filter bank plus a logsumexp), so recurrent depth has
  nothing to add. The HRM's one-step (truncated) gradient is a handicap on a task like this.
- **Thinking longer when harder: only partly.** Mean segments rise from 1.00 (easy, entropy < 0.06) to
  1.43 (moderately ambiguous), then fall back to 1.00 for the most ambiguous examples (entropy near log 6).
  This inverted U is what the ponder-cost reward asks for: extra segments are spent only where they
  improve agreement with the teacher, and nothing helps on evidence that is truly uninformative. The
  overall rank correlation with entropy and noise is therefore slightly negative (-0.05).
- **Accuracy vs budget is flat.** Forced 3 segments gives the lowest KL (0.0055 vs 0.0069 at 1 segment).
  Beyond that nothing changes, so the model has converged after 1-3 segments.
- **Speed:** on this toy task the exact teacher is a single matrix multiply, so it is 250x faster than
  the HRM when batched. The "fraction of the compute" gate only becomes meaningful with a teacher that
  has to roll out the world model for each hypothesis.
- Held-out cause: the students' confidence drops (max-prob 0.49 vs 0.60), matching the teacher (0.49).
  No "unknown" head exists yet.
